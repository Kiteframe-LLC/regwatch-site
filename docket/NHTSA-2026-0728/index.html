Structural Integrity

Pass 5 Structural Integrity: 🚩 Nuts · Implementation Reality (scaled 100%)

Why: The proposal changes the control and verification architecture for a safety-critical braking standard while several safeguards are deferred or left to manufacturer specifications.

Worst defect: Accountability Inversion 2

High-stakes domain: yes - The proposal governs braking performance and safety-critical warnings for motor vehicles.

Material Flaws

Flaw Severity Explanation Evidence Comment leverage
Accountability Inversion 2 Independent compliance assurance may depend substantially on manufacturer specifications and demonstrations for ADS-only brake inputs. Brake Controls and Test Specifications: The notice states that manufacturer specifications are used for the brake control input when testing vehicles without manually operated driving controls. Ask NHTSA to specify independent audit and reproducibility requirements.
Self-Policing Substitution 2 The proposal does not clearly identify how NHTSA will verify a manufacturer-defined command interface without relying on manufacturer demonstrations. Brake Controls and Test Specifications: NHTSA would request data and demonstration of vehicle braking performance from vehicle manufacturers if unable to test the vehicles independently. Request a standardized, inspectable test interface or equivalent third-party verification.
Constraint Sequencing Capture 2 The rule would enable ADS-only designs while related ADS decision-making tests are being developed separately. Executive Summary: NHTSA is in the process of developing safety performance tests for ADS-equipped vehicles, which would be implemented in a separate standard. Ask whether deployment should be conditioned on specified interim ADS safeguards.
Implementation Fantasy 2 The proposal assumes workable manufacturer-specific testing while acknowledging that standardized methods may only be developed over time. Brake Controls and Test Specifications: Laboratory and regulatory compliance testing procedures may be developed and implemented over time. Request concrete interim procedures, acceptance criteria, and failure handling.
Magic Interface Dependency 2 The safety and testing model depends on translating an electronic ADS command into physical braking without specifying a common interface or timing metric. Brake Controls and Test Specifications: The notice gives manufacturer specifications as the proposed test input but does not set a standardized command protocol or latency threshold. Ask for command timing, signal integrity, and degraded-mode requirements.
Impact Denial 2 The categorical no-negative-impact conclusion is broader than the supporting operational analysis in the available record. Executive Summary: The proposal states that it would remove unnecessary regulatory burdens and costs with no negative impact to vehicle safety, while detailed evidence on ADS timing and passenger response is not provided. Ask NHTSA to qualify the conclusion and publish the supporting evidence.
Safeguard Absence 2 The NPRM does not establish common minimum requirements for passenger stop requests, warning acknowledgment, or fallback communication. Brake Controls and Test Specifications: The notice expects passengers to have a means to direct an ADS-operated vehicle to stop but does not propose a standardized minimum. Ask for accessible, reliable, testable passenger safeguards.
Accountability Substrate Degradation 2 Removing conventional controls while deferring ADS performance testing may reduce immediate, legible accountability for failures. Executive Summary: The rule separates physical brake testing from ADS performance and says the latter will be addressed in a separate standard. Ask how incident data, defect reporting, and corrective action will work before the separate standard is complete.
Harm Before Review 2 The proposal may enable new ADS-only vehicle configurations before the future ADS test framework is operational. Brake Controls and Test Specifications: NHTSA says testing procedures may be developed and implemented over time as vehicles without manually operated driving controls become more common. Request phased implementation or interim evidence and monitoring conditions.
Structural Coherence 2 The rule is coherent as a physical-braking modernization but incomplete as a complete safety architecture because key ADS control and monitoring elements are deferred. Executive Summary: The proposal maintains stopping distance but treats whether brakes are actuated appropriately in a driving scenario as an independent ADS-performance question. Ask NHTSA to align the FMVSS amendment with concrete interim ADS-performance safeguards.
